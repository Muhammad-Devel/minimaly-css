# Minimaly CSS

**Minimaly CSS** — bu yengil, semantic va murakkab klasslardan xoli bo‘lgan CSS framework. U orqali oddiy HTML bilan zamonaviy, responsiv UI yaratishingiz mumkin. Tailwind yoki Bootstrap kabi emas — bu framework minimal kod bilan qulaylikni maqsad qiladi.

---

## ✨ Xususiyatlar

- ✅ Yengil va minimal o‘lcham (5KB atrofida)
- ✅ Avtomatik responsivlik
- ✅ Semantic class nomlar (`.btn`, `.card`, `.dropdown`, `.modal` va h.k.)
- ✅ Hech qanday JavaScript kutubxonasi talab qilinmaydi
- ✅ Asosiy komponentalar: button, modal, card, alert, dropdown, layout
