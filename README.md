# minimaly-css

Yengil, avtomatik responsiv, semantic va oddiy interaktiv komponentali CSS framework.

## O'rnatish

```bash
npm install minimaly-css
```

## CDN orqali

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/minimaly-css@1.1.0/dist/index.css">
<script src="https://cdn.jsdelivr.net/npm/minimaly-css@1.1.0/dist/minimaly.js"></script>
```
